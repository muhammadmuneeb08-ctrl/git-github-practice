# git-github-practice

This is my practice repository for learning the everyday Git and GitHub workflow. I use it to try things out safely: making a branch, committing small changes, pushing, and merging through a Pull Request.

## What I practiced here

- Cloning a repository to my computer
- Creating and switching branches (`practice-task`)
- Staging and committing changes with clear messages
- Pushing a branch to GitHub
- Opening and merging a Pull Request into `main`
